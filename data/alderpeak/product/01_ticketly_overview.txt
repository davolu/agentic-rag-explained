Title: Ticketly overview
Store: product

Ticketly is Alderpeak's help desk. Teams share inboxes, use macros, and can turn on single sign-on. Ticketly also includes Flare, a live inbox activity feed, so teammates can see new tickets arrive. Teams can attach files to tickets. If a team is hitting a file cap, it is usually the 25 MB per-file size cap, not a plan storage pool. If you are a Growth customer and want to claim a credit for last Monday's API outage, this overview is not the right page. It does not list a credit amount, a duration, or plan prices.
